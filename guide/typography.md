# Typography

Source: [`tokens/typography.json`](../tokens/typography.json).

## To be written

- **Typefaces:** one for titles, one for text and interface, at most two. Both must cover
  Romanian diacritics (ș ț with the comma below) and Cyrillic, carry a licence that allows
  self-hosting, and be served from Konta's own domain.
- **Sizes:** the scale for titles, lead, body, small text, with the site and app sizes
  separately (the app is denser).
- **Numbers:** tabular figures for amounts, Romanian number format (`12 400,00`), where the
  currency goes, alignment in tables.
- **Writing:** case, button labels, the product's own terms.
